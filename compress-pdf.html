Compress PDF Online

Reduce the file size of a PDF by re-rendering each page as a compressed image. This works especially well on scanned documents and photo-heavy PDFs. Everything runs locally in your browser.

🔒 Nothing uploaded ⚡ Instant, on-device 🆓 Free forever

How to Use This Tool

  1. Upload the PDF file you want to shrink.
  2. Choose a quality level — higher compression means a smaller file but lower image quality.
  3. Click “Compress PDF” and download the result.

Supported Formats

Input: PDF. Output: PDF (rebuilt from page images).

Limitations

  • This method rebuilds each page as an image, so text will no longer be selectable or searchable in the output.
  • Text-heavy, mostly-vector PDFs may not shrink much, and can occasionally end up larger, since they’re being converted to images.
  • Best results are on scanned documents or PDFs with large embedded photos.

Frequently Asked Questions

Will compression always reduce the file size?

Not always. Because this tool works by rendering pages as images, a PDF that’s already small or text-only may not shrink, and in rare cases can grow slightly. It works best on scanned or image-heavy PDFs.

Will I lose text selection after compressing?

Yes — since compression rebuilds each page as an image, the resulting pages are images, so text can no longer be selected, searched, or copied.

Is there a file size limit?

There’s no artificial limit set by Stampr, but very large PDFs depend on your device’s memory and processing power, since everything happens locally.

Is my file uploaded to a server?

No. Compression happens entirely in your browser.
