Privacy Policy

Last updated: August 2026.

We don’t receive your files

Stampr's PDF and image tools run entirely in your browser using JavaScript. When you select or drop a file into a tool, it is read and processed locally on your device. Stampr has no server-side file storage or processing, so we never receive, see, or store the files you convert.

Third-party resources

To render this site and run its tools, your browser loads some resources from third-party content delivery networks (for fonts and JavaScript libraries such as PDF.js, pdf-lib, SheetJS, JSZip, docx, and heic2any). Loading these resources may expose your IP address and browser information to those providers, the same way it would for any website that uses external fonts or script libraries.

Cookies and analytics

Stampr does not set its own cookies and does not include any analytics or tracking scripts. If you deploy this project yourself and add analytics, update this page to reflect that.

Changes to this policy

This page may be updated from time to time. Continued use of the site after changes means you accept the updated policy.

Contact

Questions about this policy can be sent through the Contact page.
